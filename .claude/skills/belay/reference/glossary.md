# Glossary

| Term | Meaning |
|---|---|
| Belay | The app, and the coordinator character in the notch |
| Climber | One running agent session (yours or a crew member's) |
| Rope drop | An agent needs you (approval or question). The RopeCard appears. |
| Catch / falls caught | RiskEngine intercepted a dangerous action |
| Summit / dangling | Task done / error, stuck or timed out |
| Route / pitch | A repo / one agent task |
| Base camp | The expanded notch home |
| Logbook | History, stats, daily share card |
| Holds | Notch widgets (music, timer…) |
| Chalk bag | Shelf/clipboard |
| Side quests | Small optional cards while agents work |
| Grades | User level, 5.6 → 5.15 |
| Crew / rope team | Sub-agents: Lead (code), Porter (Mac errands), Tempo (music), Scout (browse), Sketch (draw) |
| Engine / runtime | What a member thinks with: your `claude` CLI, `codex` CLI, a local model, an API key, or Fake |
| Taint | Marker on a turn that read untrusted content. It forces cards for risky follow-ups. |
| SceneSpec | Sketch's validated drawing format |
| Lower everyone | Stop all crew turns and their process groups |
| Conversion wheel | The radial format picker that opens when you drop files on the notch |

**Feature ID prefixes:** A agents · B notch life · C voice · D drawing · E feel · F side quests · G logbook · H trust/setup · I ecosystem · J hands · K crew · L convert.
